# Hamdelan Topics Digest
A calm, private, ad-free news and research digest by Hamdelan Iranian Cultural House.
Live: https://digest.hamdelan.org.au · Main site: https://hamdelan.org.au

Settings (layout, feedback email, API address) are in `config.js`. The API address is also listed in the
`connect-src` part of the Content-Security-Policy meta tag in `index.html`; change both together.
